Muar Road GIS Asset Management Portal1. Project OverviewThe Muar Road GIS Asset Management Portal is a comprehensive web-based application designed to assist agencies in managing road infrastructure, assessing life cycle costs (LCCA), and visualizing assets spatially. The system integrates an external ArcGIS Dashboard with native data tables and authentication mechanisms to provide a secure, all-in-one management experience.2. Key FeaturesArcGIS Dashboard Integration: Embeds a fully functional Esri ArcGIS dashboard allowing spatial filtering, road section selection, and budget visualization directly within the portal.Road Project Registry: A dynamic, filterable table for viewing, adding, editing, and deleting road projects. Records include start/end kilometers, mix categories, distress types, and cost estimations.Life Cycle Cost Analysis (LCCA): A dedicated module that presents pavement alternatives ranked by NPV (Net Present Value), initial cost, and maintenance cost ratio.Secure Authentication System: A custom-built, invite-only login system utilizing PHP sessions and secure password hashing (bcrypt). All API endpoints and dashboard pages are protected from unauthorized access.Interactive Native Map: A Leaflet-based map integration that dynamically highlights selected road segments using coordinates when a user clicks a record in the registry.Night / Light Mode Toggle: A built-in theme switcher that allows users to seamlessly switch between a modern dark mode and a clean light mode, persisting their preference locally.3. Technology StackFrontend: HTML5, CSS3 (Custom Design System with Variables), Vanilla JavaScript, FontAwesome, Google Fonts (Inter, Outfit).Backend: PHP (REST API architecture for CRUD operations).Database: MySQL (InnoDB engine).Mapping: Esri ArcGIS (Embedded via iframe), Leaflet.js (Native).4. Database Schema StructureThe application utilizes three primary tables within the muar_road_db database:users: Stores agency credentials, including an auto-incrementing ID, unique email, and hashed password.road_projects: Stores all asset records (road name, route number, km range, pavement alternatives, costs, distress analysis).lcca_results: Stores computed cost analyses and rankings for various pavement alternatives (e.g., CRMA, SFM, CMA, LATEX).5. Deployment & SetupTo deploy this portal on a local or production server:Install a web server environment stack (e.g., WAMP, XAMPP, or LAMP).Import the schema.sql file into the MySQL server to create the muar_road_db database and its tables.Place the project files into the web server's document root (e.g., htdocs for XAMPP, www for WAMP).Open config.php and verify the database connection credentials (DB_HOST, DB_USER, DB_PASS, DB_NAME).Navigate to the application URL in a web browser.
